GitHub 静态部署与数据规范

本项目已全面支持 PC 端与移动端完美自适应，采用数据库解耦架构：

  • index.html：响应式网页、五维 Canvas 雷达图自适应引擎、相似度算法。
  • data.js：包含全部 50 道历史决策题与 18 位领袖画像，免除本地 CORS 跨域限制。
  • data.json：标准纯 JSON 格式数据备份。

GitHub Pages 一键部署流程

  1. 在 GitHub 新建仓库（如 history-quiz）
  2. 将 index.html、data.js 和 data.json 一起上传到仓库根目录
  3. 进入仓库 Settings → Pages，Source 选择 Deploy from a branch (main / root)
  4. 保存后 1 分钟即可在全球任意 PC 或手机浏览器通过公开网址畅玩！

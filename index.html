GitHub Pages 一键部署流程

  1. 在 GitHub 上新建仓库，如 history-decision-quiz
  2. 将本 HTML 文件命名为 index.html 并推送到仓库主分支
  3. 进入仓库 Settings → Pages，Source 选择 Deploy from a branch (main / root)
  4. 等待 1 分钟即可通过 https://<username>.github.io/history-decision-quiz/ 访问！
